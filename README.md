# Solar System Asteroid Simulator
A Three.js and WebGL-powered visualisation of 1.4 million NASA-identified small bodies orbiting the sun.

[See the live demo here.](https://melodious-sunburst-6dc0e1.netlify.app/) Click and drag to rotate the camera. Scroll to zoom in and out.


## Implementation Notes
- I did early experiments with cubesphere terrain, and the prototype still lives in the repository for reference ([`cubesphere.js`](scripts/cubesphere.js)).
